# Local Settings

## Emotiv Cortex SDK

`EmotivCortexSettings.asset` is generated by the Cortex SDK editor window:

```text
Tools > Emotiv Cortex SDK
```

This file stores `ClientId` and `ClientSecret` as plain Unity YAML. It is intentionally ignored by Git.

Each developer should create/configure this file locally:

1. Install `com.emotiv.cortex`.
2. Open `Tools > Emotiv Cortex SDK`.
3. Enter local development `Client ID` and `Client Secret`.
4. Save configuration.
5. Do not commit `EmotivCortexSettings.asset`.

If a build pipeline needs credentials, inject them securely through CI secrets or a future SDK-supported secure mechanism instead of committing them to source control.
